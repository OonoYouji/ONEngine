# Rendering Roadmap (2026/05/03)

本エンジン (ONEngine) のレンダリング機能を強化するためのロードマップです。

## フェーズ 1: パイプラインの基盤強化とデータ駆動化（短期）
現在のハードコードに近い部分を解消し、柔軟な描画構成を可能にします。
*   **Pipeline の外部ファイル化:** PSO (Pipeline State Object) の設定を YAML 等の外部ファイルからロード可能にし、C++ の再ビルドなしにレンダリング設定を変更可能にする。
*   **Shader Reflection の実装:** HLSL コンパイル時に Root Signature やリソースレイアウトを自動抽出し、C++ 側でのディスクリプタ設定を自動化する。
*   **Texture Bindless の完全統合:** 全テクスチャを巨大な Descriptor Heap で管理し、シェーダー側でインデックス指定のみで参照可能にする。
*   **ループの正常化:** 現在の `Sleep(500)` や「10フレームに1回のUpdate」を解除し、安定したフレームレートでの描画とデータ抽出（Extract Phase）を実現する。

## フェーズ 2: マテリアル・アセットシステムの洗練（中期）
`schema.yaml` と連携した高度な表現をサポートします。
*   **Material-to-Shader 選択システムの構築:** アセットとしてマテリアルが任意のシェーダーを選択・適用できる仕組みを構築。
*   **meta ファイルの活用:** テクスチャの圧縮設定やラップモード等を meta ファイルで定義し、ロード時に反映する。
*   **Clustered Forward の最適化:** ライトカリングの計算精度向上と、動的ライトの最大数拡張。

## フェーズ 3: アニメーションとジオメトリの高度化（中期）
ECS の利点を活かした大量のオブジェクト描画を実現します。
*   **GPU Animation の実装:** ボーン行列の計算を Compute Shader もしくは頂点シェーダーで行い、数千体のキャラクターが動く環境を構築。
*   **Geometry Pool の高度化:** 静的・動的メッシュのメモリ管理を最適化し、フラグメンテーションを防ぐ GC (Garbage Collection) 機構の導入。
*   **GPU-Driven Culling のブラッシュアップ:** HZB (Hierarchical Z-Buffer) を用いた、より厳備なオクルージョンカリングの実装。

## フェーズ 4: ポストエフェクトとビジュアル品質（長期）
「アニメ調」を含む多彩な表現を完成させます。
*   **高度なポストプロセス:** アウトライン抽出の精度向上、ブルーム、トーンマッピングの調整機能の拡充。
*   **影の高度化:** Cascaded Shadow Maps (CSM) の実装と、ソフトシャドウ対応。
*   **VFX システムの統合:** ECS ベースの GPU パーティクルシステムの実装。

## フェーズ 5: プロファイリングと最適化（継続的）
*   **GPU Profiler の実装:** エンジン内蔵の UI でパスごとの負荷（ミリ秒単位）を確認できる仕組み。
*   **マルチビュー・マルチウィンドウの安定化:** ゲームビューとエディタビューを独立して高効率に描画する。
