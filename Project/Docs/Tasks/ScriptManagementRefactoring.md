# 課題: C#スクリプトの管理・配置の最適化

## 現状の課題
- 現在、C#スクリプトのソースファイル（.cs）は `SubProjects/ONEngine.Scripting/Scripts` に配置されている。
- ProjectViewは `Project/Assets` のみを表示しているため、ユーザーが作成したスクリプトがエディタ上で見えず、ドラッグ＆ドロップ（DD）によるアタッチができない。
- スクリプトとアセット（モデル、マテリアル等）の管理場所が分離しており、プロジェクト構成が直感的でない。

## 解決策: スクリプトのAssetsフォルダへの統合
スクリプトファイルを `Project/Assets/Scripts` ディレクトリに配置し、エンジンおよびビルドシステムがそこからファイルを認識・ビルドする構成に変更する。

### メリット
1. **エディタ操作の向上**: ProjectViewからスクリプトが確認でき、エンティティへのDDアタッチが容易になる。
2. **プロジェクト管理の簡略化**: 全てのゲーム固有資材（Assets）が一つのディレクトリに集約される。
3. **Unity/Godotライクな体験**: 一般的なゲームエンジンの慣習に合わせることで学習コストを低減する。
