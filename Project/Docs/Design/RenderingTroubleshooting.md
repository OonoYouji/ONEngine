# Rendering Troubleshooting

## DXGI_ERROR_DEVICE_HUNG (RemoveDevice)

GPUがハングし、ドライバによってデバイスが強制終了されるエラー。本エンジンでの主な原因と対策は以下の通り。

### 1. 同期不足（CPUによるバッファ書き換えとGPU参照の競合）
- **原因**: GPUがまだ描画に使用している定数バッファや構造化バッファを、CPUが `Update` (memcpy) してしまった。
- **対策**: `BeginFrame()`（フェンス待機を含む）の後に `Extract()`（バッファ更新）を呼ぶようにフローを厳格化する。

### 2. 不正なドローコール（バッチングミス）
- **原因**: 複数の異なるメッシュ（サブメッシュ）を1つのバッチにまとめて描画しようとした。
- **詳細**: `Renderer.cpp` において、`subMeshIndex` が異なるものを同一バッチに含めると、GPUが誤ったインデックス範囲や頂点オフセットを参照し、無効なメモリアクセスが発生してハングする。
- **対策**: バッチ生成時の比較条件に `subMeshIndex` を必ず含める。

### 3. 未初期化のリソース参照
- **原因**: シェーダーに渡す `D3D12_GPU_VIRTUAL_ADDRESS` が 0 または未初期化だった。
- **対策**: `RenderContext` に渡す全アドレスの有効性を確認し、無効な場合は 0 をセットしてシェーダー側でガードする。

### 4. コンピュートシェーダーの暴走
- **原因**: `AnimationSystem` 等の Compute Shader 内で無限ループや範囲外アクセスが発生した。
- **対策**: スレッド数（`Dispatch`）とバッファサイズの整合性を確認する。
