# ONEngine Editor Manual (2026/05/20)

ONEngine エディターの主要機能と操作方法についてのガイドラインです。

## 1. 基本構成 (Views)
エディターは以下の5つの主要ウィンドウで構成されています。

### ■ Hierarchy (ハイライト・階層管理)
- **エンティティのツリー表示**: シーン内の全エンティティを親子構造で表示。
- **ドラッグ＆ドロップによる親子化**: エンティティを他のエンティティに重ねることで親子関係を設定可能。
- **並べ替え**: エンティティ間の境界にドロップすることで、描画・更新順（SortOrder）を変更可能。
- **アクティブ切り替え**: チェックボックスでエンティティの有効/無効を即座に切り替え。

### ■ Inspector (詳細設定)
- **コンポーネント編集**: 選択中エンティティの全コンポーネントパラメータを編集。
- **アセットインスペクター**: `.mat` (マテリアル), `.pipeline`, テクスチャなどのアセットファイルを直接編集・プレビュー。
- **マテリアル保存 [NEW]**: `.mat` ファイルの色などを編集すると、即座に JSON ファイルへ保存。
- **スクリプト・リフレクション**: C# スクリプトの `[SerializeField]` フィールドを自動検出し、エディター上で編集可能。

### ■ Scene View (3Dビューポート)
- **カメラ操作**: 
    - 右ドラッグ: 回転
    - W/A/S/D/E/Q: 移動
    - Shift + 移動: 加速
- **ギズモ操作 (ImGuizmo)**: 
    - W: 移動 / E: 回転 / R: スケール
    - Local/World 座標系の切り替え。
    - スナップ機能 (Ctrlキーまたは設定で有効化)。
- **マウスピッキング**: シーン上のオブジェクトを直接クリックして選択。
- **ドラッグ＆ドロップ生成 [NEW]**: Project Browser からアセットをドロップしてエンティティを生成。
    - `.prefab`: プレハブのインスタンス化。
    - `.obj / .fbx`: モデルを割り当てた新規エンティティの生成。

### ■ Project Browser (アセット管理)
- **ファイルシステム連携**: `Assets/` ディレクトリ内のファイルをアイコン付きで表示。
- **ナビゲーション**: 進む/戻る、パンくずリスト、Ctrl+マウスホイールによるタイルサイズ変更。
- **コンテキストメニュー**:
    - フォルダ/マテリアルの新規作成。
    - 削除・リネーム・複製・コピペ。
    - エクスプローラーで開く。
- **タブ管理**: 複数のディレクトリをタブで同時に開くことが可能。

### ■ Console (デバッグログ)
- **ログ表示**: エンジン、スクリプト、エディターからのメッセージを表示。
- **フィルタリング**: Log, Warning, Error の種別ごとに表示を切り替え。

## 2. ショートカットと操作 (Shortcuts)

| キー | 機能 |
| --- | --- |
| **W / E / R** | ギズモ操作切り替え (Translate / Rotate / Scale) |
| **Ctrl + Z** | 元に戻す (Undo) |
| **Ctrl + Y** | やり直し (Redo) |
| **Ctrl + S** | シーン保存 |
| **Ctrl + Click** | Project Browser で新しいタブで開く |
| **Mouse 4/5** | Project Browser の戻る/進む |

---

## 3. ワークフロー (Workflow)

### アセットの割り当て
Inspector の `AssetPicker` (Button) に対して、Project Browser からファイルをドラッグ＆ドロップすることでアセットを割り当てます。

### コンポーネントの追加
Inspector 下部の "Add Component" ボタンから、検索フィルタを用いて新しいコンポーネントを追加できます。

### シーンの管理
上部メニューの `File` からシーンの保存・読み込みが行えます。最後に開いていたシーンは、次回起動時に自動的に復元されます。
